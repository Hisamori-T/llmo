## 🔢 API クレジット制度の詳細

### クレジット消費の仕組み

```
診断1件実行時の消費量:

簡易レポート生成: 5クレジット
  → スコアリング + AI分析

詳細レポート生成: 20クレジット
  → 競合比較 + テンプレート生成 + PDF作成

Phase 3 自動実行: 10クレジット/回
  → 月次診断 × 4回 = 40クレジット

API 直接呼び出し: 1クレジット/呼び出し
  → ダッシュボード外からの利用

合計例:
  簡易レポート3件（15クレジット）
  + 詳細レポート2件（40クレジット）
  + Phase 3 月4回（40クレジット）
  = 95クレジット/月
```

### クレジット追加購入の仕組み

```
Starter プラン:
  基本 100クレジット/月
  追加: +100クレジット = 1,000円
  
  ※ 月中に追加購入した場合、
    その時点からの日割り計算
    
Pro プラン:
  基本 500クレジット/月
  追加: +100クレジット = 800円
  
Enterprise プラン:
  基本 2,000クレジット/月
  追加: +100クレジット = 500円

例）Pro で 600 クレジット必要な月:
  基本 500 + 追加 100 = 600
  追加費用: 800円
  その月の請求: 15,000 + 800 = 15,800円
```

## 📈 月額の自動計算ロジック

### Backend ロジック（疑似コード）

```python
def calculate_monthly_charge(user):
    """月額請求額を自動計算"""
    
    # 1. 基本プラン料金
    base_price = get_plan_base_price(user.plan)
    # Starter: 5,000 / Pro: 15,000 / Enterprise: 50,000
    
    # 2. 追加アカウント料金
    additional_accounts = user.total_accounts - get_plan_included_accounts(user.plan)
    account_price = calculate_additional_account_price(
        user.plan, 
        additional_accounts
    )
    
    # 3. API クレジット追加料金
    monthly_credit_usage = get_monthly_credit_usage(user)
    included_credits = get_plan_included_credits(user.plan)
    credit_price = 0
    
    if monthly_credit_usage > included_credits:
        excess_credits = monthly_credit_usage - included_credits
        credit_price = calculate_credit_price(user.plan, excess_credits)
    
    # 4. Phase 3 運用追加料金
    phase3_runs = user.phase3_monthly_runs
    included_phase3 = get_plan_included_phase3(user.plan)
    phase3_price = 0
    
    if phase3_runs > included_phase3:
        additional_runs = phase3_runs - included_phase3
        phase3_price = calculate_phase3_price(user.plan, additional_runs)
    
    # 5. 合計計算
    subtotal = base_price + account_price + credit_price + phase3_price
    
    # 6. 年払い割引適用
    if user.billing_cycle == "yearly":
        total = subtotal * 12 * 0.9  # 10% off
    else:
        total = subtotal
    
    return {
        "base_price": base_price,
        "account_price": account_price,
        "credit_price": credit_price,
        "phase3_price": phase3_price,
        "subtotal": subtotal,
        "discount": subtotal * 0.1 if user.billing_cycle == "yearly" else 0,
        "total": total
    }
```
